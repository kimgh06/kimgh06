건물 임대 관리 회사가 매일 쓰는 건물관리 종합 시스템을 백엔드와 프론트엔드 양쪽에서 개발하고 운영했습니다. 약 7개월 동안 8개 저장소에 약 3,600개를 커밋했고, 3인 팀 코드의 약 절반을 맡았습니다(1분기 기준 49%). 퇴사 전에는 도메인 15개를 다루는 인수인계 문서 세트를 작성했습니다.

**운영 규모** (원격 DB에서 직접 센 값)
- 계약 약 3천 건
- 월 청구서 수천 건 발행과 입금 자동 대조
- 민원 2만 건 이상
- 알림톡·문자 발송 기록 92만 건

## 기능 영역별로 한 일

- **전자계약 (신규 구축)**
  - 임대차 템플릿, 임대인·임차인·중개사 3자 전자서명, OTP 본인인증, 서명 순서 제어, PDF 생성, 외부 연동 API를 만들었습니다
  - V2 에디터(PDF 배경 레이어, 자동저장)를 개발했습니다
  - 외부 전자계약 서비스를 대체해 건당 수수료를 없앴습니다
- **가계약 → 전자계약 → 입주 체크리스트 → 퇴실 정산**
  - 끊겨 있던 계약 흐름을 하나로 연결했습니다
  - 가계약 화면을 전면 리디자인하고, 가계약 취소, 계좌 분리, 중개보수 설정을 추가했습니다
- **청구·수납·정산**
  - 월세·관리비 청구서의 자동 생성, 발송, 입금 자동 매칭, 미납·연체 관리를 맡았습니다
  - 청구 금액 오류와 연체 판정 기준 불일치를 고쳤고, 입금 데이터가 함께 삭제되지 않도록 보호했습니다
  - 관리비 엑셀 대량 업로드를 만들었습니다
- **세금계산서·현금영수증**
  - 발행 파이프라인(발행 계획, 발행, 로그)을 개발하고 Popbill·Tilko를 연동했습니다
- **민원·작업지시**
  - 입주민 민원 → 작업요청서 → 견적 입찰 → 작업자 수행 → 작업명세서 보고로 이어지는 흐름을 확장했습니다
  - 모바일 현장 처리와 참고 사진 첨부를 추가했습니다
- **점검·체크리스트**
  - 템플릿 기반 정기점검·순찰, 호실별 반복 섹션, 이상 여부 분류를 만들었습니다
- **알림톡·SMS**
  - 카카오 알림톡이 실패하면 SMS로 넘기는 발송 경로를 하나의 함수로 통일하고, 템플릿을 관리했습니다
- **AI**
  - 통화를 STT로 받아 요약하고 민원을 분류하며, 직원 할 일을 자동 생성합니다 (연결 데이터 2만 건 이상)
  - 임차인 챗봇도 만들었습니다
- **검침·공과금**
  - Playwright로 한전·도시가스·수도 요금을 자동 조회합니다
- **입주민 포털**
  - 민원, 공지, 커뮤니티, 결제 조회, 안건 투표를 만들었고, 포털 전용 JWT를 씁니다
- **권한·요금제**
  - 워크스페이스·건물 단위 접근 제어와 요금제별 기능 차등을 맡았습니다
- **성능**
  - 느린 페이지 7개를 최적화하고, 대시보드를 개선하고, 대량 처리 API를 만들었습니다
  - 필터와 탭 상태를 URL에 저장해 새로고침과 링크 공유가 가능하게 했습니다
