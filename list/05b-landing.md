- **RimoAI** (2025.05~10): 인테리어 업체가 고객과 견적을 짤 때 쓰는 초안 이미지 생성 플랫폼입니다. 모노레포와 자체 CLI로 팀 환경변수를 동기화하고, GitHub Actions와 Docker로 Lightsail 배포 파이프라인을 만들었습니다.
- **3D 인테리어 프리뷰** (2025.05~06): 가구 데이터와 방 치수로 방을 만들고 실제 자재를 텍스처로 입힙니다. 조명과 그림자, 반사 때문에 80%대이던 GPU 점유율을 40%대로 낮춰 모바일에서도 60fps가 나오게 했습니다.
- **Travel-drug.com** (2025.12~): 여행 갈 때 이 약을 가져가도 되는지 알려 주는 서비스입니다. 공공데이터의 제약사 제품 목록과 미국 FDA 규제 물질을 CSV 하나로 가공해 Q&A 페이지를 만들었고, 이후 검색과 챗봇을 붙였습니다.
